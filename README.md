# 🃏 Carte UNO - Gioco Educativo per Bambini con Esigenze Speciali

Applicazione web **single-page** (HTML, CSS e JavaScript vanilla) progettata per supportare attività educative, logopediche o di potenziamento cognitivo con bambini con esigenze speciali.

## 🎯 Come funziona
L'attività abbina il supporto digitale alle carte fisiche:
1. Il bambino ha davanti a sé le **40 carte numeriche** di un mazzo UNO (numeri da `0` a `9` nei 4 colori: Rosso, Blu, Verde e Giallo).
2. All'avvio, l'app estrae e mostra una carta a schermo.
3. Il bambino individua la carta corrispondente sul tavolo e la mette via.
4. Premendo **PROSSIMA CARTA**, viene estratta una nuova carta. **Ogni carta esce una sola volta** per partita (mescolamento Fisher-Yates senza reinserimento).

## ✨ Caratteristiche
- **Zero dipendenze**: un unico file `index.html` eseguibile su qualsiasi browser, tablet o LIM anche offline.
- **Alta leggibilità e accessibilità**: grafica stile UNO ad alto contrasto, etichetta testuale esplicita (`COLORE + NUMERO`) per rinforzare l'associazione visiva e pulsanti ampi.
- **Feedback chiaro**: contatore delle carte rimanenti sempre visibile e schermata finale di rinforzo positivo al completamento del mazzo.

## 🚀 Avvio rapido
Scarica il file `.html` e aprilo direttamente con un doppio clic in qualsiasi browser moderno (Chrome, Safari, Edge, Firefox) oppure pubblicalo gratuitamente tramite GitHub Pages / Vercel.
